# Basic Machine Learning Projects

This repository contains beginner-friendly machine learning projects built as part of my learning journey. Each project demonstrates a complete ML workflow — from data exploration to model building and evaluation.

## 📁 Projects

### 1. Diabetes Prediction
A classification project that predicts whether a person is likely to have diabetes based on health-related features (such as glucose level, BMI, age, blood pressure, etc.).

**Notebook:** `Diabetes_Prediction.ipynb`

**Key steps covered:**
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature scaling
- Model training (e.g., Logistic Regression / Decision Tree / SVM)
- Model evaluation (accuracy, confusion matrix, etc.)

### 2. House Price Prediction
A regression project that predicts house prices based on features like area, number of rooms, location, and other property attributes.

**Notebook:** `House_Price_Prediction.ipynb`

**Key steps covered:**
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training (e.g., Linear Regression)
- Model evaluation (R² score, MAE, RMSE)

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Jupyter Notebook

## 🚀 How to Run
1. Clone this repository
   ```bash
   git clone <your-repo-url>
   ```
2. Install the required dependencies
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```
3. Open the notebooks
   ```bash
   jupyter notebook
   ```
4. Run the cells in order for each project.
